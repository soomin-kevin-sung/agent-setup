# AGENTS.md

Codex에서 사용할 프로젝트 지침 파일의 원본입니다.

## 적용 방식

- 새 프로젝트에서 Codex를 사용할 때 이 파일을 프로젝트 루트의 `AGENTS.md`로 복사합니다.
- 공통 규칙은 `../shared/common.md`를 기준으로 유지하고, Codex에서만 필요한 규칙을 이 파일에 추가합니다.

## Codex Guidelines

- 작업 전 관련 파일과 현재 변경 사항을 먼저 확인합니다.
- 사용자가 구현을 요청한 경우 가능한 한 직접 수정하고 검증합니다.
- 사용자가 만들지 않은 변경 사항은 되돌리지 않습니다.
- 파일 편집 후 필요한 테스트나 검증 명령을 실행합니다.
- 완료 보고에는 변경 사항과 검증 결과를 간결하게 포함합니다.
