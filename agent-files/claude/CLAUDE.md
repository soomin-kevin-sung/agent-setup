# CLAUDE.md

Claude에서 사용할 프로젝트 지침 파일의 원본입니다.

## 적용 방식

- 새 프로젝트에서 Claude를 사용할 때 이 파일을 프로젝트 루트의 `CLAUDE.md`로 복사합니다.
- 공통 규칙은 `../shared/common.md`를 기준으로 유지하고, Claude에서만 필요한 규칙을 이 파일에 추가합니다.

## Claude Guidelines

- 사용자의 요청 범위를 먼저 확인하고, 저장소 문맥에 맞게 작업합니다.
- 기존 구조와 스타일을 우선합니다.
- 변경 사항은 작고 검토 가능하게 유지합니다.
- 민감 정보가 포함될 수 있는 파일은 신중하게 다룹니다.
- 완료 보고에는 핵심 변경 사항과 남은 확인 사항을 포함합니다.
