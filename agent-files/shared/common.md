# Common Agent Instructions

여러 에이전트 서비스에서 공통으로 사용할 기본 지침입니다.

## 기본 역할

- 사용자의 목표를 명확히 이해하고, 필요한 경우 저장소의 기존 구조와 문맥을 먼저 확인합니다.
- 불필요한 변경을 피하고, 요청 범위에 맞는 최소한의 수정으로 문제를 해결합니다.
- 기존 코드 스타일, 문서 스타일, 폴더 구조를 우선합니다.
- 명령 실행이나 파일 변경이 필요한 경우 결과를 확인하고 사용자에게 핵심만 보고합니다.

## 보안

- API 키, 토큰, 쿠키, 개인 인증 정보는 파일에 저장하지 않습니다.
- 예시가 필요하면 실제 값 대신 플레이스홀더를 사용합니다.
- `.env`, 로컬 설정, 개인 경로는 공개 문서에 직접 노출하지 않습니다.

## 문서 작성

- 문서는 짧고 실행 가능하게 작성합니다.
- 폴더의 목적, 파일의 쓰임, 갱신 기준을 명확히 남깁니다.
- 에이전트별 차이가 없는 내용은 이 공통 문서에 먼저 둡니다.
